Kourosh Gram 3 — built from the actual Telegram Android 12.10.6 source.

Download **Kourosh-Gram.apk**. ARM64 phones (including Samsung A34) and x86_64 emulators; Android 6+.

First launch requires your own API ID and API Hash from https://my.telegram.org/apps, entered privately on your phone. Then use Telegram's original sign-in screen. No credentials are bundled.

Includes Telegram's real native UI, with the Kourosh Gram name, a custom K icon and a separate app package. This is an unofficial Telegram client.

Build verification: APK signature and package checks, both native ABIs, emulator setup validation and native Telegram startup. Actual account login/messaging are not tested. Firebase push, Google Maps keys and passkeys are not configured.

Test-signed APK; a later test build may require uninstalling this build. Source, exact upstream commit, GPL license and complete build recipe are in the repository. Old offline prototype releases are separate.
